## Installation

### Windows

1. Download `krino-dokim-windows-setup.exe`
2. Run the installer and follow the on-screen prompts
3. Launch **KRINO Dokim** from the Start Menu or desktop shortcut

**First-run note:** Windows SmartScreen may show a warning on first launch. Click **"More info"** → **"Run anyway"**.

---

### macOS

1. Download `krino-dokim-macos.dmg`
2. Open the DMG and drag **KRINO Dokim** to your Applications folder
3. Right-click the app → **Open** on first launch

---

### Linux

1. Download `krino-dokim-linux.deb`
2. Install:
   ```bash
   sudo dpkg -i krino-dokim-linux.deb
   ```
3. Launch from your application menu or run `krino-dokim`

**Prerequisite (Ubuntu/Debian):**
```bash
sudo apt install python3-gi gir1.2-webkit2-4.1 libgirepository1.0-dev
```

**Prerequisite (Fedora/RHEL):**
```bash
sudo dnf install python3-gobject gtk3 webkit2gtk3
```
